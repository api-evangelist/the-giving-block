# The Giving Block

> The Giving Block is a crypto-native fundraising platform. Its Public API and
> embeddable donation widget let partners accept cryptocurrency, stock, and card
> donations on behalf of 1,000+ nonprofits, instantly converting crypto to cash so
> nonprofits never have to touch crypto.

Generated by the API Evangelist enrichment pipeline (method: generated) from the

prefer that for the machine-readable spec.

## API

- Name: The Giving Block Public API (v1.0)
- Style: RESTful, JSON, resource-oriented URLs
- Production base URL: https://public-api.tgbwidget.com
- Sandbox base URL: https://public-api.sandbox.thegivingblock.com
- Auth: JWT bearer. POST /v1/login to obtain access + refresh tokens; POST /v1/refresh-tokens to renew.
- Errors: custom JSON envelope (errorMessage, errorType, errorCode, meta); requestId on every response.
- Webhooks: AES-256 encrypted donation/transaction notifications.

## Operations

- Auth: login, refreshTokens
- Organizations: GetOrganizationsList, GetOrganizationById, UpdateOrganization, GetWidgetSnippet, GetWidgetUrl
- Currencies & rates: GetCurrencyListV1, GetCurrencyListV2, GetCryptoToUSDRate
- Crypto donations: CreateDepositAddress
- Stock donations: GetBrokersList, GetTickersList, GetTickerCost, CreateStockDonationPledge, SubmitStockDonation, SignStockDonation
- Card / fiat donations: CreateFiatDonationPledge, ChargeFiatDonationPledge
- Testing: CreateTestDonation
- Transactions: GetTransactionList, GetTransactionByUuid
